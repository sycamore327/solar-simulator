# Solar Simulator · 太阳系模拟器

**一个跑在浏览器里的 3D 太阳系。真实轨道、真实数据、点一下就能看资料。**

🔗 **在线体验：<https://sycamore327.github.io/solar-simulator/>**
📦 **源码仓库：<https://github.com/sycamore327/solar-simulator>**

手机和电脑是同一个网址，会自动切换成适合屏幕的版本。

---

## 这是什么

把太阳系搬进网页。

它不是一个视频，也不是一张静态图 —— 是一个可以**拖、可以缩放、可以点、可以调时间**的 3D 沙盒：

- 八大行星按**真实的轨道要素**运行，位置、快慢、倾斜都照真实数据来；
- 鼠标**移到**任何一颗天体上会浮出它的资料卡，**单击**可以锁定它；
- 对着可飞行的天体按 <kbd>F</kbd>，镜头会平滑飞过去，贴着它的表面看；
- 底下一条时间轴，从 **0.01 倍**（慢慢挪）一路拉到 **10 万倍**（公转变成流动的光环）。

## 设计理念

### 1. 「真实」优先于「好看」

这不是一个凭感觉摆几颗球的动画。每颗天体的位置都来自 **JPL 的轨道要素**，用开普勒方程逐帧求解，所以：

- 行星**近日点快、远日点慢**，是真的；
- 地球轨道几乎是正圆、火星轨道明显是个椭圆，是真的；
- 冥王星会**走进海王星轨道内侧**，是真的。

好不好看是加分项，**跑得对不对是底线**。

### 2. 数据要能读，不是摆设

做资料卡的时候定了一条规矩：**能用大白话说清的，就不用术语堆**。

> 「土星平均密度只有 0.687 g/cm³ —— 比水还小。如果有个足够大的水池，土星能浮起来。」

而不是「密度 687 kg/m³」。宁可少写一行数据，也要让人**记住一件事**。

### 3. 眼睛舒服 > 特效多

中途有一版被吐槽「那一坨坨，非常没有美观性」。问题出在小行星带：一块一块实心石头堆在一起，糊成一条脏兮兮的带子。

改法是**反直觉的 —— 变少、变淡**。参考了 [hyqzz/Solar-Wanderer](https://github.com/hyqzz/Solar-Wanderer) 的做法：真实的小行星带本来就极稀疏，肉眼望去应该是一盘**细腻的尘埃**，而不是一串石头。于是改成统计点云，颗粒调小、透明度调低，反而更像真的。

同理，手机上直接**关掉泛光后处理**、把星点数量减半 —— 眼睛舒服、手机不发烫，比多那点特效重要。

### 4. 离线自足

整个网站**没有一个外部链接**：Three.js 引擎、16 张贴图、图标，全部下载到本地（约 15 MB）。

这样它不依赖任何 CDN，断网也能开，多年以后也不会因为某个网站挂了而变成白屏。也正因为如此，它需要一个小小的本地服务（浏览器不允许直接读本地图片当贴图）—— 所以配了一个 `start.bat`，双击就行。

### 5. 留一点性格

工具可以冷冰冰，作品不必。所以有了入场时那艘 Q 弹的像素小飞船，和右下角那个会空翻、会晕圈、会冒颜文字的小宠物。

它俩其实是**同一个东西**：v0.1 里那艘 13×8 的像素 UFO，被留了下来，一路长成了加载动画和陪伴的小宠物。

## 技术实现

| 部分 | 做法 |
| --- | --- |
| 引擎 | Three.js **r160**（ESM，本地 vendor） |
| 结构 | **单个 `index.html`**，HTML + CSS + JS 全在里面，方便分享和托管 |
| 行星轨道 | 开普勒轨道要素 + 牛顿迭代解 Kepler 方程；数据来自 JPL |
| 小天体 | 轨道要素取自 **JPL SBDB API**（真实观测解） |
| 距离比例 | 真实距离在屏幕上会挤成一团，所以加了一条混合曲线：`upa = 基准/√a`，在「压缩」和「真实 1:1」之间平滑过渡 |
| 星带 | 统计点云（确定性伪随机 + √r 径向分布 + 高斯倾角），`sizeAttenuation:false` 让远处的点不至于糊掉 |
| 发光 | UnrealBloomPass 后处理；太阳颜色推到 HDR 区间，只有它越过阈值 |
| 拾取 | Raycaster；无模型天体用 `THREE.Sprite` 点 |
| 像素画 | 画到「1 像素 = 1 格」的离屏 canvas，再整数倍放大 + 关掉插值 → 边缘干脆、不发虚 |
| Q 弹 | 挤压拉伸（`sx = 1+k, sy = 1−k`）+ `easeOutBack` 回弹 |
| 移动端 | `matchMedia` 判断窄屏，降画质；CSS 媒体查询自适应，三个控制窗都能最小化 |

## 本地运行

**最简单：双击 `start.bat`。**
它会自己找一个可用的 Python，在 8000 端口起一个本地服务，然后打开浏览器。关掉那个黑窗口 = 停止。

> 为什么不直接双击 `index.html`？
> 因为浏览器有个安全策略：`file://` 打开的页面**不允许读取本地图片当贴图**，行星会变成一片白。起个小服务是正确做法，将来搬到 GitHub Pages 也是同一套。

**手动起也行**（在项目目录下）：

```sh
python -m http.server 8000
```

然后打开 <http://localhost:8000>。
